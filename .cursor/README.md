# Cursor Project Configuration (Broker Desk)

## Purpose

This directory contains non-authoritative Cursor adapters for this repository.
Use them to enter the repository's current governance context and to invoke
local skills on demand.

## Entry

- `.cursor/rules/00-governance-entry.mdc` is the sole Cursor adapter entry.
- Files under `.cursor/skills/` are on-demand pointers or local task aids;
  they are not independent project documentation.

## Maintenance

Keep this README descriptive. Governance, current progress, task scope, and
role procedures belong in the repository documents named by the adapter entry.

# TASK-026 / 建立可复用非生产 QA 环境

- 状态: Blocked
- 优先级: P0
- 负责人: 技术项目经理
- 背景: TASK-025 Checkpoint D 因 QA 环境前提缺失而 Blocked
- 基线: `main` / `b54210428c819a7a0d0b48f6200fe898345b5583`
- 目标: 建立两个可合法使用的非生产租户、对应 Clerk 测试身份和可恢复的合成数据，供 TASK-025 及后续页面迁移验收复用

## 任务名称

建立可复用非生产 QA 环境

## 背景和用户结果

TASK-025 的页面实现已通过 Checkpoint C，但最终验收缺少两个明确的非生产租户、合法登录身份和可恢复合成数据。用户结果是：后续页面验收可以在不接触生产数据、不修改产品安全边界的前提下重复验证分页、滚动、租户隔离和归档恢复。

## 本次范围

允许：

- 确认或建立两个明确标记为非生产 QA 的专用租户；
- 为每个租户配置一个合法 Clerk 测试身份；
- 只使用现有正式角色，不新增虚构权限角色；
- 通过正常产品路径创建不含真实个人信息的合成记录；
- 同一对象类型至少创建 7 条记录，以支持第二页和长列表滚动验证；
- 提供至少 1 条可通过正常界面归档并恢复的记录；
- 记录租户所有权、身份用途、数据前缀、清理方法、审计历史保留和禁止生产使用边界。

## 明确不做什么

- 修改业务代码、数据库结构、149 项字段体系或产品页面；
- 修改生产数据、生产认证规则、角色权限或租户隔离；
- 创建无 `record.read` 的虚构角色；
- 关闭或削弱 Clerk、限流、认证或租户隔离；
- 复制、导出或持久化 Cookie、Token 或认证请求头；
- 直接写数据库创建、清理或恢复业务测试记录；
- 删除或修改 safety/WIP、TASK-020 或其他页面迁移内容；
- 将 QA 环境配置或测试入口部署到生产环境。

## 依赖关系

- `TASK-025` 保持 `Blocked`，本任务只负责提供其缺失的 QA 环境前提；不修改 TASK-025 页面实现。
- 依赖当前 `main` 的正式角色目录、认证和租户隔离能力；不得为本任务改造这些能力。

## 执行阶段

### A. 环境资格确认

- 确认两个租户均为非生产专用环境，并登记所有者和用途；
- 确认两个 Clerk 身份可以正常登录各自租户；
- 确认身份绑定的角色来自正式角色目录；
- 若只能依赖未确认的现有租户或身份，立即停止。

### B. 合成数据建立

- 使用稳定的 QA 前缀；
- 不使用真实姓名、地址、联系方式、证件或客户文件；
- 同一对象类型至少 7 条记录；
- 至少 1 条记录支持正常归档和恢复；
- 记录创建前后的数量和租户边界；
- 所有写入必须经过正常产品路径。

### C. 环境门禁验证

- 两个身份只能读取各自租户对象；
- 租户 A 不能读取、打开或归档租户 B 对象；
- URL 分页可进入第二页；
- 列表存在真实可滚动内容；
- 归档、取消、成功/失败反馈和恢复路径可重复；
- 清理后记录恢复到约定状态；审计历史残留如实登记。

### D. 交接

- 保存脱敏环境清单、数据清单和验证证据；
- 不保存认证凭据；
- 独立确认环境门禁后，解除 TASK-025 的 QA 环境阻塞，TASK-025 只继续执行 Checkpoint D；
- 不把 QA 环境通过表述为业务页面或输出产品通过。

## 停止条件

出现以下任一情况立即停止并报告：

- 无法证明租户是专用非生产环境；
- 需要修改 Clerk、认证、权限、租户隔离或数据库结构；
- 需要直接写数据库或复制认证凭据；
- 发现真实个人信息或生产数据；
- 无法通过正常产品路径归档和恢复；
- 两个身份不能分别证明租户边界；
- 测试数据无法安全清理或所有权不明确。

## 验收标准

- 环境清单、身份用途和角色记录完成；
- 两个租户均可正常登录；
- 同一对象类型至少 7 条合成记录可分页和滚动；
- 至少 1 条记录完成归档/恢复闭环；
- 第二租户隔离证据通过；
- 无真实个人信息、无敏感凭据、无生产数据；
- `TASK-025` 仍保持独立任务边界；
- 运行检查、`git diff --check` 和最终工作区状态完成记录。

## 预计涉及的模块

- 非生产环境的租户和身份管理配置；
- 现有租户成员、案件/主体/物件创建及生命周期操作路径；
- 脱敏的 QA 环境清单和验证记录。
- 不允许修改 `src/`、数据库迁移、业务 API、认证逻辑或租户权限映射。

## 风险和注意事项

- 两个现有活跃租户不能仅凭名称被认定为测试租户，必须取得环境所有者确认。
- Clerk 身份必须通过正常邀请或既有合法管理路径建立，不能复制会话凭据。
- 七条记录必须属于同一对象类型，否则不能证明第二页分页能力。
- 正常归档/恢复会产生审计历史，清理完成不等于无痕恢复。
- 如果环境所有权、身份用途或数据清理责任不清晰，立即停止。

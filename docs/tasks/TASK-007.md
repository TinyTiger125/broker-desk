# TASK-007: 诊断模板字段重复字符

- 状态: Proposed
- 优先级: P0
- 负责人: 设计者 / 诊断者
- 依赖关系: TASK-002

## 任务名称

确定模板字段重复数字来自源 PDF、overlay、旧预览状态还是数据链路。

## 背景和用户结果

在修改坐标或渲染逻辑前获得可重复证据，避免把视觉症状误修成模板损坏。

## 本次范围

- 一个可复现模板、固定案件和固定字段。
- 源 PDF、生成 PDF、overlay 配置和预览状态的逐层比较。
- 明确诊断结论和后续最小修复边界。

## 明确不做什么

- 不同时调整五张模板。
- 不直接重写 renderer。
- 不把人工拖拽当成默认质量修复。

## 依赖关系

TASK-002。

## 验收标准

1. 能稳定复现重复字符。
2. 能区分源图层与生成 overlay。
3. 能确认 case/template/data/render 的实际传递值。
4. 输出明确诊断结论或下一项修复任务。

## 预计涉及的模块

PDF renderer、模板运行时、视觉烟测脚本和固定模板资产。

## 风险和注意事项

诊断阶段优先只读；任何坐标改动都必须另立实现任务。

## 验证命令

npm run smoke:guarantee-visual
npm run test:guarantee-print-fit
还必须保存源 PDF、生成 PDF 和逐层比较证据。

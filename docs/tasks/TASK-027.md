## 目标结构与产品契约（Checkpoint B 已批准）

`/clients` 的唯一核心任务是：快速找到目标客户，并判断下一步应该跟进谁。

- 使用标准 List Report：紧凑标题、Filter Bar、客户结果列表/表格和明确的空结果清除动作。
- 客户名称是唯一主要进入链接；Tab 聚焦该链接，Enter 使用原生链接行为。
- 快速创建保留，但降为次于查找客户的入口；本任务运行验收不得提交新客户。
- 保留阶段、用途、温度、跟进时间/既有跟进排序和客户详情入口；不套用案件、主体、物件状态，不新增完成度、输出资格或 AI 状态。
- 搜索、阶段、用途、温度、排序和 `page` 使用稳定 URL 状态；浏览器返回应恢复查询、筛选、排序、分页、滚动和触发链接焦点。
- 不建立独立 `selected` 状态，不把客户改造成卡片墙；1440 保持高效表格/紧凑列表，768 允许次要信息换行或隐藏，390 使用可阅读紧凑结果行且不横向溢出。
- 正常客户安静展示，只有现有权威跟进信息可以适度突出；不根据字段是否填写自行推导业务状态。

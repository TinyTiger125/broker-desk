# TASK-008: 完成单一记录类型的归档恢复闭环

- 状态: Proposed
- 优先级: P0
- 负责人: 设计者、实现者、独立审查者
- 依赖关系: TASK-002

## 任务名称

先为一种记录类型完成 archive、restore、权限和审计闭环。

## 背景和用户结果

经纪人可以安全归档错误记录并恢复，管理员能看到审计证据。

## 本次范围

- 由设计者先选定一种记录类型。
- 该类型的存储字段、服务端权限、归档、恢复和审计。
- 该类型的 focused regression。

## 明确不做什么

- 不同时覆盖全部记录类型。
- 不实现物理删除或批量清理。
- 不改变模板、输入合并或输出逻辑。

## 依赖关系

TASK-002。

## 验收标准

1. 未授权用户不能归档或恢复。
2. 归档后默认查询行为明确。
3. 恢复后记录和关联关系可用。
4. 归档与恢复都产生审计事件。
5. 重复操作是幂等或给出明确错误。

## 预计涉及的模块

选定记录类型的数据层、Server Action、页面、迁移、权限和审计日志。

## 风险和注意事项

先完成设计任务卡补充，不得凭当前字段猜测级联关系。

## 验证命令

npm run typecheck
npm run lint
npm run test:tenant-data-access
npm run test:tenant-governance
还必须完成授权拒绝、归档、恢复、重复操作和审计记录验证。

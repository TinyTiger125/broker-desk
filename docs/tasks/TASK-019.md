# TASK-019：外部演示环境准备

- 状态: Ready
- 优先级: P0
- 负责人: 技术项目经理 / 实现 Agent / 独立审查 Agent
- 依赖关系: TASK-018

## 任务名称

在不关闭认证、限流、同源检查或租户隔离的前提下，准备可以安全交给朋友测试的外部演示环境。

## 用户结果

产品负责人能够通过真实 Clerk 登录进入专用测试租户，使用虚假测试数据完成已验证的资料处理到申请书下载闭环；临时隧道只在回调、安全和回退门禁全部通过后开放，并且可以明确关闭。

## 背景和用户结果

MIG-007 已证明本地开发模式的完整用户闭环，但 `npm start` 的生产探测仍返回 503。外部演示还缺少真实 Clerk、专用测试账号、虚假数据、双租户真实浏览器隔离、隧道回调和关闭/回退证据。本任务只解决这些外部演示门禁，不把本地 demo 通过伪装成生产就绪。

用户结果：朋友能够安全登录专用测试环境，完成已确认资料到申请书下载；测试数据和租户边界不会泄露；演示结束后入口可以关闭并回退。

## 范围

- 诊断并正确配置 `npm start` 返回 503 的全部门禁，区分缺失配置、认证、限流和外部服务问题。
- 验证真实 Clerk 登录、专用测试账号、回调 URL/隧道域名和 HTTPS 行为。
- 使用虚假测试数据和专用测试租户；验证至少两个租户之间的案件、模板安装状态、输出和下载隔离。
- 核对生产限流启用标志与策略 ID、数据发布批准、附件存储、文档读取服务、数据库迁移/角色和必要外部服务配置。
- 完成隧道开放前安全检查、敏感信息检查、测试数据清理、关闭步骤和可回退方案。

## 本次范围

- `npm start` 生产启动门禁及其配置证据。
- Clerk 真实登录、专用测试账号、回调域名、HTTPS/同源配置。
- 两个专用测试租户的虚假数据、案件/模板/输出隔离。
- 外部 OCR、附件存储、文档读取、生产数据库角色/迁移及限流策略的实际验证。
- 隧道开放前和关闭后的安全、日志、敏感信息和回退检查。

## 明确不做什么

- 不通过关闭 Clerk 认证、生产限流、同源检查、权限检查或租户隔离来绕过 503。
- 不使用真实客户资料、真实申请数据、生产密钥或未授权外部服务。
- 不把本地 `DATA_DRIVER=memory`、demo 身份或本地浏览器通过当作外部演示通过。
- 不在本卡内修改 TASK-005～008、149 项专业分类、产品范围或新增治理迁移任务。
- 未完成所有安全门禁和产品负责人确认前，不启动或分享 ngrok/其他隧道地址。

## 依赖关系

依赖 TASK-018 的 `main` 产品基线和 A/B 浏览器闭环；不依赖或修改 safety/WIP、TASK-005～008、149 项分类或任何新的 MIG 任务。

## 验收标准

1. `npm start` 的 503 已按具体原因分类，并有配置变更、验证结果和回退方式；没有安全绕过。
2. 真实 Clerk 登录和专用测试账号可用；隧道域名已加入允许的回调/同源配置，登录返回路径正确。
3. 仅使用虚假数据的专用测试租户可完成资料确认到申请书预览/下载闭环；必要的真实外部 OCR、附件和文档服务状态有证据。
4. 第二个测试租户无法读取第一个租户的案件、模板安装状态、预览或下载；普通运营角色不能进入平台管理页面。
5. 下载内容与预览对应，刷新/重新登录后必要状态仍存在；缺少数据、缺少模板和生成失败有明确可恢复反馈。
6. 隧道开放前已检查敏感信息、日志、测试数据、账号权限、回调域名、关闭步骤和回退点；关闭后外部入口不可用。
7. 无法自动验证的真实登录、外部服务和隧道行为明确记录为“需要人工验证”，不得伪称通过。
8. 独立审查完成；工作区干净；实现 Agent 和审查 Agent 均已退出。

## 风险和注意事项

- 503 可能是多个连续门禁的组合；只修复首个错误并不代表服务已可开放。
- 生产配置正确但真实 Clerk/外部服务未完成请求验证时，仍必须停止隧道开放。
- 测试账号、虚假资料和日志必须按可撤销、可清理、可回退方式管理；不得把朋友账号当作长期生产账号。
- 资料处理器返回 422 的人工恢复仍是降级路径，不得称为真实 OCR/自动处理通过。

## 验证命令

- `npm start` 及四个关键路由的 HTTP 探测。
- 真实 Clerk 浏览器登录、回调返回和会话刷新。
- 双测试租户案件、模板安装、预览和下载的允许/拒绝矩阵。
- 下载文件打开、预览/下载内容一致性、错误恢复和重新登录状态保留。
- 敏感信息、日志、测试数据和隧道开放/关闭检查。
- `git diff --check`、workflow rules、必要静态检查和独立审查。

## 1. 用户可观察结果

在一个非生产测试经营主体内，使用管理员上下文作为公司表格管理员，并使用同一经营主体内的独立普通成员上下文验证输出权限：

1. 上传一份测试用客户空白 PDF；
2. 手工放置文本、日期和复选框；
3. 将这三个字段绑定到案件字段；
4. 用测试案件预览并发布公司自建蒙板；
5. 普通成员从案件选择该表格，预览并生成文件；
6. 管理员修改蒙板并发布第二版；
7. 第一版历史文件的内容和版本记录保持不变。

这条切片必须直接证明“管理员做蒙板，普通成员用蒙板生成文件”，而不是只证明一个编辑器或一个数据库对象存在。

## 5. 验收步骤与证据

### A. 管理员制作并发布

1. 固定测试经营主体和管理员身份；
2. 上传一页空白 PDF，确认上传者声明；
3. 在页面中手工放置一个文本字段、一个日期字段和一个复选框；
4. 将三个位置分别绑定到案件字段；
5. 使用测试案件预览，确认值出现在预期位置；
6. 发布公司自建蒙板 v1，记录版本和操作者。

**通过证据**：管理员能看到草稿、测试结果和已发布 v1；普通成员在本切片及第一版产品中始终不能移动坐标或进入蒙板编辑入口。

### B. 普通成员生成文件

1. 以普通成员上下文进入案件；
2. 选择该测试表格；
3. 系统匹配已发布公司自建蒙板 v1；
4. 预览并生成文件；
5. 记录案件版本、表格指纹、蒙板版本、操作者和时间。

**通过证据**：普通成员可以生成文件，但没有坐标编辑入口；预览和生成文件使用同一 v1 关系。

### C. 修改蒙板并验证历史不变

1. 管理员修改一个字段位置或校验并发布公司自建蒙板 v2；
2. 重新生成或预览时使用 v2；
3. 打开之前生成的 v1 文件和版本记录；
4. 对比 v1 与 v2 的文件、表格指纹、蒙板版本和时间记录。

**通过证据**：v1 文件内容和版本记录保持不变；v2 只影响后续生成；失败时可回到 v1。

## 6. 失败状态与回滚

- PDF 损坏、加密、密码保护或不支持：拒绝上传并允许换一份测试表格；不承诺自动识别全部真实客户资料；
- 字段绑定或预览失败：保留草稿，不能发布；回到管理员校准；
- 发布失败：不改变线上活动版本，保留草稿；
- 普通成员匹配失败：停止生成，显示原因和回到管理员校准/更换表格的路径；
- 文件生成失败：不改变案件、不写入新的成功历史，不覆盖 v1；
- v2 导致问题：活动版本回退 v1，保留 v2 草稿和失败审计；
- 任一失败影响现有生产行为：关闭切片开关，恢复 TASK-037 / G1-SLICE-0 基线，不继续扩大范围。

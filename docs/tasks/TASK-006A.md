# TASK-006A: 案件详情页返回案件整理中心

- 状态: Proposed
- 优先级: P1
- 负责人: 实现者 / 独立审查者
- 依赖关系: TASK-002

## 任务名称

案件详情页提供明确入口，返回案件整理中心。

## 背景和用户结果

经纪人从案件详情页完成查看后，可以通过页面内返回入口回到案件整理中心，而不是回到未筛选的整理首页。

## 任务目标

案件详情页提供明确入口，返回案件整理中心。

## 候选标准地址

/organize-center?type=case

## 本次范围

- 只处理案件详情页的页面内返回入口。
- 明确直接访问或刷新案件详情页时的固定返回目标。
- 建立浏览器验收场景。

## 明确不做什么

- 主体编辑页。
- 物件编辑页。
- 未保存表单警告。
- 浏览器后退行为。
- 生命周期操作 returnTo。
- 保留搜索词 q。
- 全局导航重构。

## 依赖关系

TASK-002。

## 验收标准

以下仍是候选验收标准；本卡保持 Proposed，未授权实施。

1. 从案件详情页点击页面内返回入口，进入 /organize-center?type=case。
2. 整理中心显示案件类型，而不是全部类型。
3. 直接通过 deep link 打开案件详情页后，返回入口仍然有效。
4. 刷新案件详情页后，返回入口仍然有效。
5. 不改变主体和物件页面行为。
6. 不改变案件生命周期操作。
7. 相关类型检查、Lint 和浏览器验证通过。

## 预计涉及的模块

src/app/cases/[id]/page.tsx、整理中心案件类型筛选和浏览器验收记录。

## 风险和注意事项

安全分支已有 /organize-center 的候选实现，但没有满足固定 query 标准；
该实现不应直接进入本任务的 Ready 或 Done。

## 验证命令

npm run typecheck
npm run lint
浏览器验证页面内返回、案件类型筛选、deep link 和刷新。

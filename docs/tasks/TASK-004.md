# TASK-004: 收敛模板库与官方模板边界

- 状态: Proposed
- 优先级: P0
- 负责人: 实现者 / 独立审查者
- 依赖关系: TASK-002

## 任务名称

收敛普通用户模板库和平台管理员官方模板工厂的前台、后台边界。

## 背景和用户结果

普通经纪人只看到浏览、安装和使用；平台管理员才能编辑和发布官方模板。

## 本次范围

- /templates 模板库。
- /platform/templates 兼容入口和单模板编辑入口。
- 角色可见性、安装状态、更新时间和返回路径。

## 明确不做什么

- 不实现 draft/publish 数据模型。
- 不调整 PDF 坐标或视觉布局。
- 不修改租户 RLS 或外部 Clerk 配置。

## 依赖关系

TASK-002。

## 验收标准

1. 普通用户不能看到官方编辑或发布动作。
2. 平台管理员可从模板库进入对应官方编辑页。
3. 旧入口不会展示第二套模板列表。
4. 安装、未安装、更新时间和返回路径清晰。

## 预计涉及的模块

模板页面、平台会话、模板权限和发布检查脚本。

## 风险和注意事项

角色边界必须由服务端权限检查决定，不能只隐藏 UI。

## 验证命令

npm run typecheck
npm run lint
npm run test:guarantee-template-publication
npm run test:tenant-governance
浏览器验证普通用户和平台管理员的可见性。

## 当前状态

Proposed。

# TASK-034 / W11-CORE 目标结构与有限实现边界

## 共同规则

- 只在页面层重排现有事实和动作；不新增 API、保存逻辑、权限、租户、数据库或状态算法。
- 使用 Layout System V1 的页面头部、Filter Bar、结果区和次级操作语言；正常信息安静，异常和恢复动作突出。
- 不修改 `src/app/clients/page 2.tsx`、TASK-020、输出/模板/报价专题。

## `/clients/[id]` Object Page

- 页头：客户名称、真实联系方式/区域摘要、编辑主入口；提案入口保持次级并指向现有冻结路线。
- 首屏：客户基本事实与持久化阶段、用途、温度；法定信息作为独立章节。
- 独立章节：跟进历史及新增动作、报价记录、任务；保留现有动作和权限。
- 删除推导阶段建议、路径徽章和多组快捷动作；工作流说明只作为安静辅助，阶段更新保留现有单一表单，不显示完成度、AI确认或输出资格。

## `/contracts` 与 `/service-requests` Worklist

- 页头和筛选：页面身份、记录数量和分页；合同状态筛选因无独立权威状态冻结。
- 结果区：明确表头、稳定记录标识、物件/主体关联事实和记录日期；不显示客户阶段推导状态或报价金额冒充合同事实。
- 当前合同没有可证明的权威状态、金额或维护 Action；不显示状态/金额，不暴露批量更新或导出，避免空选择全量导出和客户阶段误写。
- 删除伪 KPI、时间线、静态活动、随机图片、模板/输出入口和第二选中模型。
- 768px 压缩列，390px 使用连续信息行，不使用最小宽度硬压桌面表格。

## `/audit-log` List Report

- 页头、Filter Bar、只读结果区和分页/空态；日志字段只来自审计记录。
- 桌面显示表头与行；390px 将时间、执行人、动作、对象、消息、context 按行分组。
- 保留现有 CSV 链接和 `audit.view` 权限，不显示绩效/风险 KPI。

## 允许文件

- 四个目标页面、必要的页面专属结构代码、TASK-034 契约脚本与治理文档。
- 默认禁止修改 actions、API、hub/data 适配、数据库、认证、权限、租户及其他矩阵页面。

## 停止条件

- 通过专项契约脚本、typecheck、lint、build、workflow rules、diff check 和独立只读审查。
- 统一服务探测最多一次；失败记为 `UNVERIFIED`，不循环排查。
- 一次批次提交后停止，不自动进入第二批。

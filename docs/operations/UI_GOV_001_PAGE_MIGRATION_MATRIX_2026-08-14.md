## 1. 结论先行

### 批准后的推荐迁移顺序

以下是顺序建议，不是本轮新建的实施任务；每一步都必须单独获得批准：

1. **UI-GOV-002A：最小视觉基础**——只定义 Token、按钮、字段、章节、焦点和密度，不做全站替换。
2. **UI-GOV-003：案件总览 Object Page**——以 TASK-020 为参考，补齐响应式字段组、操作层级和真实浏览器验收。
3. **UI-GOV-002B：公共页面骨架**——只提取已经在案件总览中验证过的动态头部、锚点、章节、字段组和编辑面板。
4. **信息整理中心**——明确 List Report/Worklist 与案件 Object Page 的职责边界。
5. **输出中心与申请书预览**——验证案件事实到正式文书的连续体验。
6. **资料导入**——按 Wizard 整理上传、识别、归属、新建/追加/合并决策。
7. **模板库**——在租户可见性和安装持久化边界稳定后治理。
8. **首页/工作台**——最后汇总前面已经稳定的任务状态和入口。

P1/P2 页面暂不提前适配。这个顺序是迁移风险顺序，不是产品价值排名；首页最后处理是为了避免虚构 KPI、重复入口和脱离真实状态的仪表盘。

### 主要反对意见

**不能直接按“所有页面统一换皮”实施。** 当前页面同时包含案件主流程、旧的对象管理入口、平台管理和报价/合同工作流。批量改 CSS 只能统一表面，不能解决多个业务权威和多个页面类型混在一起的问题；还会把 TASK-020 未验证的响应式/键盘问题误当成已解决。

推荐先冻结页面类型和共享外壳的验收合同，再按完整用户流程迁移。代价是首轮不会快速产生全站视觉变化，但可以避免重复实现、错误权限入口和无法回退的半成品布局。

## 5. 视觉和交互风险清单

### 已能从源码确认的风险信号

- 页面存在多套标题、说明、按钮和卡片组合，尚未由统一页面类型组件约束。
- 多个列表页使用原生表格和固定最小宽度；窄屏是否能完成筛选、读行和操作尚未证明。
- `/import-center`、`/output-center`、`/service-requests` 等页面同时承载多个工作阶段，首要任务和异常层级需要真实页面验收。
- 一些页面使用高饱和背景、渐变操作或大量嵌套白色卡片；这是结构可读性风险信号，不等于已证明视觉失败。
- 客户、主体、物件、案件、合同和报价存在多条相互链接的入口；如果未经业务边界核对就统一布局，可能把不同权威混成一个对象。
- 主页、Board、Workspace 可能承担相似的“下一步工作”入口；不能只用视觉差异掩盖入口重复。

### 只能列为 `UNVERIFIED` 的风险

- 真实视口下的首屏是否被异常、KPI 或说明文字占满。
- 滚动时动态头部、锚点、当前章节和返回位置是否可靠。
- Tab 顺序、焦点恢复、Esc 取消、抽屉焦点陷阱和屏幕阅读器语义。
- 768px、1024px、窄屏和 200% 缩放下的表格、锚点、编辑面板和固定操作。
- 中、日、韩长文本是否造成截断、换行错位或操作溢出。
- 普通租户、平台管理员、不同成员角色和第二租户看到的页面及操作是否正确。

## 6. 迁移实施边界和回退方式

### 不能按整文件迁移的页面

- `/import-center`：必须以资料上传→映射→确认/恢复→归属结果的完整流程为边界，不能单独抽取一块卡片。
- `/cases/[id]`：必须保留 C+ 案件数据、异常、编辑、预览和下载门禁的连贯性；不把 Object Page 壳复制成新案件系统。
- `/templates` + `/output-center` + 两个申请书预览路由：必须按模板可见性、安装、案件选择、预览和下载的闭环迁移，不能只改模板卡片。
- `/clients`、`/parties`、`/properties`：先确认实体权威和关系，再决定共用索引/详情结构；不按外观相似直接合并。
- `/platform/templates` 与 `/templates`：权限边界必须先于视觉复用，不能整文件共享管理员行为。

### 后续每页实施必须补齐的证据

- 普通、空、加载、错误、权限拒绝、输出阻塞至少各一条状态证据。
- 桌面、平板、窄屏截图或录屏；键盘操作和焦点恢复记录。
- 中文、日文、韩文长文本；术语来自当前唯一规范来源。
- 租户和角色隔离；不把静态构建、lint 或 typecheck 当作权限/浏览器通过。
- 改动前后的截图对照、业务回归、独立审查和可回退提交。

本轮只改治理文档，回退仅需撤销本任务的单一治理提交，不影响运行代码、数据库、认证、租户隔离或 safety/WIP。后续页面实施必须在独立任务和明确回退点上逐个推进，不能使用全站一次性替换。

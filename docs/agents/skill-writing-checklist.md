# 项目级 Skill 编写检查清单

> 用于 Broker Desk 的项目级 skill、agent、自动化流程和操作规程。目标不是让模型“更聪明”，而是把重复工作变成可复核、可停止、可维护的流程。

## 使用方式

1. 新建或修改 skill 前先完成 Gap gate。
2. 按顺序填写清单；任何一项无法证明时标记为“阻塞”，不得猜测跳过。
3. 完成后执行文档中写明的验证命令，再决定 `Ready`、`Blocked`、`Extend existing` 或 `Skip`。

## 0. Gap gate

- [ ] 能指出同一工作流至少重复两次，或能证明它会稳定且高成本地重复。
- [ ] 已说明输入、输出、边界、停止条件和失败路径。
- [ ] 已检查现有 `skills/`、`.agents/`、自动化、`AGENTS.md`、`docs/`，确认没有可直接复用的资产。
- [ ] 已决定 `extend existing`、`new skill` 或 `skip`，并写出选择理由。
- [ ] 如果工作流仍依赖临时判断、一次性上下文或未确认的产品决策，选择 `skip`。

## 1. Contract

- [ ] 名称准确描述能力，不用宽泛的“万能助手”命名。
- [ ] 描述是路由契约：明确何时触发、何时不触发、输入是什么、最终产物是什么。
- [ ] 明确模型触发与用户显式调用的边界。
- [ ] 正面触发至少有一个，负面不触发至少有一个。
- [ ] 主流程按执行顺序书写；每一步都有可检查的完成标准。
- [ ] 任何分支、错误路径、权限不足或外部服务失败都规定停下、报告和恢复动作。

## 2. Workflow

- [ ] 先复现或确认事实，再提出假设；不把猜测写成事实。
- [ ] 把任务拆成一个缺陷或一个页面，避免跨范围修改。
- [ ] 每次修改后运行一个明确的验证命令，并保存命令与结果。
- [ ] 验证通过立即提交当前范围；下一项工作开新任务。
- [ ] 不推送、不改生产或主测试环境，除非用户明确授权。
- [ ] 保留用户已有改动；不会用清理命令覆盖未相关的工作区内容。

## 3. Information design

- [ ] 使用渐进披露：主 skill 只放入口、主流程和停止条件，细节放在按需引用的 reference。
- [ ] 引用最多一层深；避免把同一规则复制到多个文件。
- [ ] 关键术语与产品领域词汇先定义，再在全文保持一致。
- [ ] 维护单一事实来源；项目规则、租户边界、字段定义和验证入口不在多个文档重复维护。
- [ ] 面向用户的文字不得泄露内部字段、模型推理、调试信息或实现术语。

## 4. Safety and data boundaries

- [ ] 明确租户、账号、角色和资源的授权边界；默认拒绝越权访问。
- [ ] 不在 skill、日志或示例中写入密钥、令牌、个人证件或真实客户资料。
- [ ] 删除、归档、发布、覆盖、批量替换等不可逆动作必须有确认、审计和恢复路径。
- [ ] AI 只能提取、分类、比较、推荐或生成候选；不得静默确认、静默覆盖或代替人工承担业务责任。
- [ ] 跨设备结果依赖服务端持久化和版本化资产，不能依赖本地浏览器或机器状态。

## 5. Validation

- [ ] 正面触发验证：命中正确入口并完成预期产物。
- [ ] 负面触发验证：不满足条件时不误触发。
- [ ] 覆盖空值、无效值、过期数据、权限不足、外部服务失败和中断恢复。
- [ ] 验证重复执行是否幂等；不会重复创建、重复发布或重复写入。
- [ ] 验证命令会产生可见的 `PASS`、`CHECK` 或等价结果。
- [ ] 对页面改动检查关键路径、错误状态和可见文案；对数据改动检查租户隔离、迁移和回滚。
- [ ] 记录“已验证 / 未验证 / 被阻塞”，不得用“看起来正常”代替证据。

## 6. Maintenance

- [ ] 标注负责人、适用范围、状态和最后复核日期。
- [ ] 触发条件、数据模型、权限模型或验证命令变化时重新复核。
- [ ] 定期检查重复 skill；能合并就合并，不能证明价值就删除或标记 `Skip`。
- [ ] 活跃进度只写入 `docs/operations/CURRENT_WORKING_CONTEXT.md`。
- [ ] 不再创建综合性 `PROJECT_MEMORY`；稳定事实写入各自唯一规范来源，历史快照只用于追溯、不作当前依据。

## Project-specific non-negotiables

- 一条任务只解决一个缺陷或一个页面；修改后验证，验证通过立即提交。
- 当前产品只有一个权威活动进度文件；不得用新文档替代它。
- 官方输出模板由管理员维护和发布；用户下载后只能影响自己的模板副本。
- 模板位置、版本和字段映射必须服务端持久化，保证跨电脑一致。
- 信息整理独立于输出；输出检查不能反向污染输入工作台。
- 任何 AI 预匹配、读取或推荐都必须保留证据、状态和人工确认入口。

# 保证公司申请书专题：完整用户流程合同

- 制定日期：2026-08-18
- 状态：G0 产品合同补充；不授权实现
- 统一入口原则：普通成员从案件进入，填写层管理者从配置管理进入，平台人员从适配申请后台进入

## 1. 普通成员从案件生成申请书

| 项目 | 合同 |
| --- | --- |
| 操作者/入口 | 普通成员；案件详情或案件工作流中的“生成申请书”入口 |
| 读写对象 | 读取本租户案件事实、保证公司选择、已发布租户填写层和申请书补充字段；只写本次输出草稿和最终输出快照 |
| 权限 | 案件读取/业务输出权限；只能使用本租户已发布且精确匹配的配置；无坐标移动、发布、停用或平台配置权限 |
| 成功状态 | 选择案件 → 选择保证公司 → 系统选定匹配配置 → 补齐差异字段 → 预览 → 确认输出 → 下载/交付；快照记录案件、原件指纹、字段目录版本、填写层版本和操作者 |
| 阻断状态 | 无已发布配置、四态不是“精确匹配”、必要字段缺失、案件版本冲突、输出渲染失败、权限失效 |
| 恢复路径 | 先补齐案件/补充字段；若匹配问题，停止并提交模板管理者；不得由普通成员修正坐标；恢复后重新进入预览 |
| 审计结果 | 记录预览、确认、下载、阻断原因、所用版本和操作者；失败不生成成功输出快照 |

## 2. 模板管理员安装平台配置

| 项目 | 合同 |
| --- | --- |
| 操作者/入口 | 公司负责人或被授予模板管理能力的成员；经营主体的兼容配置目录 |
| 读写对象 | 读取平台兼容配置目录项和版本；写入租户安装快照，不复制或取得第三方原件 |
| 权限 | 经营主体内模板管理能力；不能修改平台基础层；配置必须满足权利/技术准入 |
| 成功状态 | 选择兼容配置 → 查看来源、版本、匹配条件和兼容说明 → 安装为租户版本 → 可进入草稿/测试；安装不等于发布 |
| 阻断状态 | 权利证据未满足、配置已停用、字段目录不兼容、原件匹配条件未知、权限不足 |
| 恢复路径 | 更换已准入配置、等待平台发布新版本或提交适配申请；已安装旧版本不被静默删除 |
| 审计结果 | 记录租户、安装者、平台版本、字段目录版本、安装时间和状态；不得记录成“官方文件已分发” |

## 3. 模板管理员上传公司原件并制作配置

| 项目 | 合同 |
| --- | --- |
| 操作者/入口 | 填写层管理者；本租户填写层管理入口 |
| 读写对象 | 写租户私有空白原件、原件指纹/版本元数据、租户填写层草稿和测试记录 |
| 权限 | 模板管理能力；上传者声明有权在本租户业务中使用；平台基础层只读 |
| 成功状态 | 上传 → 格式检查 → 私有保存 → 指纹/页面识别 → 套用基础层或从零创建 → 人工校准 → 测试案件预览 → 草稿保存 → 发布新租户版本 |
| 阻断状态 | 格式不支持、文件损坏/加密、权利声明缺失、四态非精确、字段目录不兼容、测试溢出/分页失败、发布权限不足 |
| 恢复路径 | 重新上传或更换原件；返回校准；修正字段绑定；保留失败草稿；不得修改平台基础层或让普通成员强制输出 |
| 审计结果 | 记录原件指纹、上传者、配置版本、字段目录版本、校准、测试结果、发布者和共享范围；失败只记录草稿/阻断 |

## 4. 旧原件发生变化后的重新校准

| 项目 | 合同 |
| --- | --- |
| 操作者/入口 | 系统检测到原件指纹/页数/尺寸变化，或模板管理者从版本页主动发起 |
| 读写对象 | 读取旧原件、旧填写层、历史输出；创建新原件版本和新校准草稿 |
| 权限 | 模板管理能力；普通成员不能接受变化或继续强制输出 |
| 成功状态 | 识别变化 → 旧版本标记需重新验证 → 管理者校准 → 测试通过 → 发布新版本；旧版本和历史输出保持不变 |
| 阻断状态 | 无法判断变化、锚点不一致、字段目录不兼容、测试失败、来源版本无法证明 |
| 恢复路径 | 恢复旧原件/旧版本；更换来源文件；提交适配申请；在新版本发布前继续使用仍精确匹配的旧版本 |
| 审计结果 | 记录变化前后指纹、触发原因、校准者、测试结果、发布版本和受影响配置；不覆盖旧快照 |

## 5. 向平台提交适配申请

| 项目 | 合同 |
| --- | --- |
| 操作者/入口 | 公司负责人或模板管理者；租户配置页的“请求平台适配”入口 |
| 读写对象 | 写适配申请、租户原件引用、来源/版本声明和授权范围；平台读取仅限被授权的指定租户对象 |
| 权限 | 申请人必须有本租户模板管理能力；平台人员获得临时、可撤销、可审计的处理权限，不获得默认案件访问 |
| 成功状态 | 申请提交 → 平台受理 → 交付租户专用配置；如需公共目录，另起来源/权利审核和发布流程 |
| 阻断状态 | 未声明权利、含真实客户资料、文件不完整、授权范围不清、平台无能力处理 |
| 恢复路径 | 补充来源/版本/授权、重新上传空白原件、撤回申请；不因申请提交自动公开或分发 |
| 审计结果 | 记录申请人、租户、原件指纹、授权范围、平台处理者、访问时间、交付版本和是否进入公共审核 |

## 6. 平台审核并发布公共兼容配置

| 项目 | 合同 |
| --- | --- |
| 操作者/入口 | 平台兼容配置管理者；平台后台审核入口 |
| 读写对象 | 读取适配申请/来源证据/测试结果；写公共兼容配置目录项、平台基础填写层版本和发布状态 |
| 权限 | 仅平台配置管理能力；不能因维护配置默认读取客户案件；公共发布与租户专用交付分离 |
| 成功状态 | 权利证据完整 → 技术校准/字段目录版本确认 → 测试通过 → 发布公共兼容配置；租户可在其后安装 |
| 阻断状态 | 无权利证据、原件无法合法进入公共处理、版本/字段目录不明确、测试失败、来源方要求限制传播 |
| 恢复路径 | 退回租户专用配置；补证后重新审核；公共发布失败不影响原租户私有版本 |
| 审计结果 | 记录来源证据、审查人、版本、字段目录、测试、公开范围、发布/停用原因；不记录为“官方/认证/合作”除非有书面依据 |

## 7. 直接访问预览、下载或编辑入口

| 入口 | 直接访问合同 |
| --- | --- |
| 预览 | URL 必须重新验证身份、租户、案件范围、配置发布状态、原件匹配状态和字段目录版本；不满足时显示可恢复阻断状态，不伪造预览 |
| 下载 | 只能下载当前操作者有权使用的、精确匹配且已确认的正式输出；旧链接不能绕过新门禁；下载写审计 |
| 填写层编辑 | 仅填写层管理者；直接 URL 不能把普通成员带入坐标/绑定编辑器；无权或版本不符时回到安全入口 |
| 平台配置编辑 | 仅平台配置管理者；不得借预览 URL 取得客户案件数据；authoring 与 broker 读写对象分离 |
| 恢复 | 说明缺失权限、版本不匹配、需重新校准或记录不存在的具体下一步；不把所有错误统一为“重新读取” |

## 8. 当前产品矛盾的最终裁决

普通成员**不得移动字段坐标**。遇到错位只能停止本次输出并提交填写层管理者重新校准；模板管理者发布新版本后，普通成员再生成申请书。第一版不实现普通成员“仅本次输出修正”能力，因此不产生第二套受限编辑器、临时坐标保存、额外权限或快照合同。

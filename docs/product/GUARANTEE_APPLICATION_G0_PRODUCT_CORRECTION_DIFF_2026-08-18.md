# 保证公司申请书专题 G0 产品语言纠偏差异摘要

- 制定日期：2026-08-18
- 状态：G0 产品验收通过；本摘要保留为纠偏记录，G1 仅获规划授权
- 目的：记录本轮纠偏替换的产品语言和边界，不新增治理体系，不启动 G1 或实现。

## 1. 最高依据与产品语言

| 原有风险 | 本轮纠偏后的唯一规则 |
| --- | --- |
| 用“兼容配置、填写层、租户版本、输出快照”等技术词替代用户能理解的对象 | 面向产品和用户统一使用：**客户空白表格、平台蒙板、公司自建蒙板、已生成文件**。技术词只可作为内部括注。 |
| 附件与基线各自解释产品是什么 | 《保证公司申请书：第一版产品基线》是最高产品依据；外部研究、对象、权限和迁移文档降为支持附件。 |

## 2. 三条核心流程恢复为用户任务

| 操作者 | 固定流程 | 边界 |
| --- | --- | --- |
| 普通成员 | 案件 → 选择保证公司/表格 → 系统匹配蒙板 → 补齐少量信息 → 预览 → 生成文件 | 不进入抠格子工具，不移动坐标。 |
| 公司表格管理员 | 上传本公司的客户空白表格 → 使用平台蒙板或制作公司自建蒙板 → 测试 → 发布给公司成员 | 低频管理流程；发布前由管理员校准和验证。 |
| 平台运营者 | 选择高频通用表格 → 人工制作平台蒙板 → 测试 → 在法律和质量条件满足后提供给客户 | 不向客户分发保证公司原始 PDF 或完整表格图片。 |

## 3. 五套现有配置的定位修正

- 统一称为“五套现有平台蒙板”，不称官方模板、官方原件或保证公司官方产品。
- 不删除、不废弃、不把它们判定为永久不能输出。
- 可作为 G1 的真实测试样本，继续用于匹配、校准、预览、输出链路验证，并保持现有生产行为不变。
- 在上线前法律确认完成前，不向新客户正式上架这五套平台蒙板；能否作为商业产品面向所有客户提供，列为上线前法律确认项。这只关闭具体商业上架门，不阻断通用 G1 建设，也不扩大为绝对的新输出禁令。
- 客户仍须上传自己合法取得的客户空白表格；Broker Desk 不提供保证公司原始 PDF、完整表格图片或高清背景。

## 4. 法律与技术门重新分离

- 已知事实：没有证据证明 Broker Desk 可以分发保证公司原始 PDF，也没有证据证明可以公开展示完整表格图片。
- 未知事项：平台自制坐标蒙板是否需要额外授权，属于上线前法律确认，不能由产品经理自行判定。
- G1 技术建设可以先验证客户空白表格、蒙板匹配、人工校准、测试预览和已生成文件链路。
- 具体五套平台蒙板面向新客户的商业上架属于上线前法律/质量门；不把该门与通用对象模型混为一谈。

## 5. 不变的产品边界

- 按经营主体订阅，内部成员不按席位收费；旧席位字段仅保留兼容，不在本轮改变生产限制。
- 普通成员不能抠格子；错位时停止并交给公司表格管理员重新校准。
- Broker Desk 自有报价单和其他自有业务表单不进入本专题。
- 不引入保证公司 API、电子签名、AI 自动画框、模板市场、跨租户共享或 TASK-020 变更。

## 6. G0 状态

本轮纠偏已通过 G0 验收。G1 现在仅可进行依赖图和切片规划，不得据此直接创建实现任务或修改业务代码；四个产品概念、三条流程、五套平台蒙板定位、原始 PDF/完整图片/蒙板边界、法律与技术门分离、普通成员坐标限制、经营主体订阅方向和专题排除项继续由本基线约束。

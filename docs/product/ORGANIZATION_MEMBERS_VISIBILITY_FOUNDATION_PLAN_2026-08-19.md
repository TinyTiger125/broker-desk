## 一、最高产品依据

Broker Desk 按经营主体销售，不按账号或席位销售。Clerk 只确认“这个人是谁”；Broker Desk 负责成员关系、经营主体归属、权限、案件/人物/物件可见范围、公司表格访问和历史文件访问。经营主体创建本身不授予无限期正式使用资格；生产业务还必须满足有效订阅、有效试用或平台批准状态，受控非生产测试可单独放行。

用户端只暴露三类能力：

1. 公司负责人：管理经营主体和成员，并可管理公司表格；
2. 公司表格管理员：在公司负责人授权下管理公司表格；
3. 普通成员：使用有权访问的案件和已发布表格生成文件。

“店长、营业担当、宅建士”等职务不自动授予系统权限。平台运营者与客户公司成员完全分离。

## 二、用户结果主链

```text
Clerk 身份
  → 本地用户
  → 经营主体成员关系
  → 公司能力预设
  → 对象可见范围
  → 公司表格权限
  → 案件输出权限
```

任一层缺失都必须给出明确状态，不得通过默认第一用户、硬编码 Clerk ID 或客户端参数补造关系。创建经营主体时，首位用户必须同时成为本地用户、active membership、公司负责人和当前工作区成员。

### 切片 1：身份、经营主体和邀请加入

- 用户结果：新负责人创建经营主体并进入 Workspace；受邀成员接受后进入同一经营主体；无关系用户看到创建经营主体/查看或接受邀请/重新登录，不循环。
- 最小交付：本地用户与 Clerk subject 唯一绑定；经营主体创建与首位成员关系原子成立（本地用户、active membership、公司负责人、当前工作区成员）；邀请记录绑定受邀邮箱与目标经营主体，状态覆盖“邀请中 → 已接受并使用中 → 已暂停/已移除”，接受身份必须匹配；Workspace 列表基于当前 subject；安全默认和审计。生产资格另由有效订阅、有效试用或平台批准状态控制。
- 前置：切片 0；现有 Clerk 开发环境或受控预发布身份；不需要第二租户。
- 验证：两个合法内部身份、一个非生产公司、正常邀请接受、退出/重进 Workspace、无关系用户 System State。
- 回滚：关闭新增入口/开关，旧登录和旧 Workspace 继续可用；不删除旧用户、旧公司或旧邀请。
- 不含：成员能力预设、对象可见范围、跨租户测试、Clerk Organizations。

### 切片 2：公司成员能力预设

- 用户结果：负责人可授予/撤销“可管理公司表单配置”；普通成员无法进入公司管理或蒙板编辑；负责人不能被全部降级。
- 最小交付：经营主体内 capability override 或等价预设；成员管理 Action；负责人保护；审计；旧八角色兼容读取。
- 前置：切片 1；不得与 TASK-038 同时修改同一模板权限门。
- 验证：负责人授权、普通成员拒绝、撤销立即生效、最后负责人保护、停用后拒绝。
- 回滚：保留旧角色权限，关闭新预设入口；公司表格读路径不删除。
- 不含：新建几十项权限开关、职务角色重命名、平台运营者权限改造。

### 切片 3：对象可见范围

- 用户结果：案件、人物、物件默认仅自己可见；主动改为公司成员可见后，同公司成员可查看但不能自动修改；三类对象分别判断可见范围，关联对象和文件不因案件分享而递归公开。
- 最小交付：三类对象各自的 visibility scope、读取/更新服务端门禁、共享只读 UI、附件/输出二次检查、旧数据安全默认。公司空白表格和已发布公司蒙板是公司共同工具；蒙板草稿仅公司负责人和公司表格管理员可管理；共享蒙板不能绕过案件权限。
- 前置：切片 1；案件/主体/物件现有数据适配和查询边界；migration 必须追加式、可回滚。
- 验证：拥有案件访问权成员可读、无权成员拒绝；分享案件不泄露私有客户/物件/原始 PDF；共享不自动允许更新。
- 回滚：关闭分享入口；旧 owner-only 读取继续工作；新增字段默认 private。
- 不含：指定成员分享、团队/部门层级、案件自动递归分享。

### 切片 4：TASK-038 正式入口接入

- 用户结果：公司表格管理员从公司表格库重开草稿、测试和发布；普通成员从有权案件选择已发布公司蒙板并生成；历史文件继承案件访问范围；同一非生产经营主体内至少具备一个负责人/表格管理员上下文和一个普通成员上下文后，才恢复 TASK-038 真实验证。
- 最小交付：把 TASK-038 harness 接到真实成员关系、公司表格能力和案件输出权限；同一蒙板服务两个案件；生成记录归公司/案件，不归个人。
- 前置：切片 1、2；本人案件的现有 `case.user_id` 规则可作为最小访问证明；切片 3 的共享范围可后续接入；不要求定向分享或完整公司案件协作先完成。
- 验证：管理员/普通成员两个合法上下文；两个案件互不串联；普通成员无编辑入口；重复生成幂等；v1/v2 历史不变。
- 回滚：关闭新正式入口，保留 TASK-038 试验页和旧五套蒙板行为；不应用 migration 时不读取新对象。
- 不含：平台蒙板目录、跨成员案件协作、多页 PDF、商业上架。

### 切片 5：接管与付费停止保留

- 用户结果：成员暂停/移除立即失去访问；业务对象仍归公司；负责人可接管并审计；停止付费进入恢复/导出期再封存。
- 最小交付：接管状态、负责人保护、审计、受控只读/导出门；六个月期限先作为可配置产品状态，正式商用前通过法律/合同门。
- 前置：切片 1、2、3；订阅系统和保留策略事实核对。
- 验证：停用后旧成员所有请求拒绝；负责人接管后对象可继续处理；历史文件不被删除或改写。
- 回滚：恢复成员或订阅状态；不物理删除历史业务对象。
- 不含：支付网关重构、法律结论、跨租户迁移。

# Documentation Archive

Archived documents are retained for traceability. They are not current source-of-truth documents.

Use current documents first:

1. `docs/PROJECT_MEMORY.md`
2. `CONTEXT.md`
3. `docs/README.md`
4. Relevant files under `docs/product/`, `docs/engineering/`, or `docs/operations/`

## Archived Groups

| Directory | Contents | Status |
| --- | --- | --- |
| `docs/archive/legacy-product/` | Early MVP scope, handoff, and development summaries. | Superseded by current product topology and project memory. |
| `docs/archive/legacy-output/` | Early Japan output package and output audit documents. | Historical market/output notes; not the current product center. |
| `docs/archive/stitch/` | Stitch redesign briefs, reviews, and implementation decision logs. | Historical UI design process and evidence. |
| `docs/archive/ux/` | Earlier foundation UX task list. | Historical task list; current priorities live in project memory and active product docs. |

## Usage Rule

Archived material may be cited as historical evidence only. Do not implement from archived documents without checking current direction in `docs/PROJECT_MEMORY.md` and `docs/README.md`.

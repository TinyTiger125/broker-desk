# Documentation Archive

Archived documents are retained for traceability. They are not current source-of-truth documents.

Use current documents first:

1. `AGENTS.md`
2. `docs/operations/CURRENT_WORKING_CONTEXT.md`
3. `BACKLOG.md`
4. `PRODUCT.md`
5. `ARCHITECTURE.md`
6. `CONTEXT.md`
7. `docs/README.md`

## Archived Groups

| Directory | Contents | Status |
| --- | --- | --- |
| `docs/archive/legacy-product/` | Early MVP scope, handoff, and development summaries. | Superseded by current product topology and relevant product documents. |
| `docs/archive/legacy-output/` | Early Japan output package and output audit documents. | Historical market/output notes; not the current product center. |
| `docs/archive/stitch/` | Stitch redesign briefs, reviews, and implementation decision logs. | Historical UI design process and evidence. |
| `docs/archive/ux/` | Earlier foundation UX task list. | Historical task list; current priorities live in BACKLOG and active product docs. |
| `docs/archive/legacy-project-memory/` | Dated snapshot of the former comprehensive project memory. | Historical evidence only; not a current task, product, architecture, or execution authority. |

## Usage Rule

Archived material may be cited as historical evidence only. Do not implement from archived documents without first checking `AGENTS.md`, `docs/operations/CURRENT_WORKING_CONTEXT.md`, `BACKLOG.md`, `PRODUCT.md`, `ARCHITECTURE.md`, `CONTEXT.md`, and `docs/README.md`.
